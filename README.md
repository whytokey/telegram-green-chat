# Веб-чат на React с использованием GREEN-API (Telegram)

Пользовательский интерфейс мессенджера для отправки и получения текстовых сообщений через сервис **GREEN-API**. 
В соответствии с условиями задания проект реализован для мессенджера **Telegram** с визуальным оформлением в стиле веб-клиента.

## Стек и архитектура
- **React 18** + **Vite**
- Модульная структура проекта:
  - `src/api/greenApi.js` — работа с методами `sendMessage`, `checkAccount`, `getStateInstance`
  - `src/hooks/useNotifications.js` — получение и удаление уведомлений по технологии `HTTP API` (`receiveNotification` + `deleteNotification`)
  - `src/components/` — UI-компоненты (`LoginScreen`, `Sidebar`, `ChatWindow`, `Icon`)

## Инструкция для локального запуска проекта

### 1. Предварительные требования
- Установленный **Node.js** (версии 18 и выше).
- Авторизованный инстанс в личном кабинете [GREEN-API](https://console.green-api.com/).
- В настройках инстанса должны быть включены уведомления о входящих сообщениях (`Получать уведомления о входящих сообщениях и файлах` -> `Да`), а поле `Webhook URL` оставлено пустым.

### 2. Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/whytokey/telegram-green-chat
   cd telegram-green-chat
2. Установите зависимости:
    npm install
3. Запустите проект в режиме разработки:
    npm run dev
4. Откройте в браузере адрес http://localhost:5173

### 3. Использование
1. На экране входа введите ваши idInstance и apiTokenInstance из личного кабинета GREEN-API.
2. В левой панели введите номер телефона получателя (например, 79991234567) или @username и нажмите +, чтобы создать чат.
3. Напишите текстовое сообщение и отправьте его — собеседник получит сообщение в мессенджере, а его ответ автоматически отобразится в окне чата.
